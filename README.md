# java-lotto-precourse

## [화면]
### 입력
- [X] : 로또 구입 금액을 입력받는다.
- [X] : 당첨 번호를 입력 받는다.
- [X] : 보너스 번호를 입력 받는다.

### 출력
- [ ] : 발행한 로또 수량 및 번호를 출력한다(로또 번호는 오름차순으로 정렬).
- [ ] : 당첨 내역을 출력한다.
- [ ] : 총 수익률을 출력한다(수익률은 소수점 둘째 자리에서 반올림).
- [ ] : 예외 상황 시 에러 문구를 출력한다.(단, 에러 문구는 "[ERROR]"로 시작해야 한다.)

## [기능]
- [X] : 1 ~ 45 범위의 무작위 6개의 숫자를 발행한다.
- [X] : 구입 금액에 해당하는 만큼 시도횟수를 반환한다.
- [X] : 시도횟수에 해당하는 만큼 로또를 발행한다.
- [X] : 로또 번호와 보너스 번호를 가지고 당첨 번호와 비교하여 맞은 개수 반환한다.
- [ ] : 맞은 개수만큼 상금 구분한다.
- [ ] : 총 상금과 구입 금액으로 수익률 계산한다.

## [예외처리]

### 금액
- [X] : 금액이 0보다 같거나 작으면 예외처리한다.
- [X] : 금액이 1000원 단위가 아니면 예외처리한다.
- [X] : 숫자가 아닌 부적절한 문자가 입력되면 예외처리한다.

### 로또
- [X] : 로또가 최소 1번 이상 발행되지 않으면 예외처리한다.
- [X] : 로또가 NULL이거나 로또리스트에 NULL값이 삽입되면 예외처리한다.
- [X] : 당첨번호는 6개의 숫자(1 ~ 45까지 범위)가 입력되지 않으면 예외처리한다.
- [X] : 당첨번호는 숫자가 아닌 부적절한 문자가 입력되면 예외처리한다.
- [X] : 보너스번호 1~45까지의 하나의 숫자가 입력되지 않으면 예외처리한다.
- [X] : 보너스번호가 숫자가 아닌 부적절한 문자가 입력되면 예외처리한다.
- [X] : 보너스번호가 당첨 번호와 중복되면 예외처리한다.
